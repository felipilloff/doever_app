# Security

Doever v0.1 is local-only and has no server, account, API key, or telemetry.
The database is not encrypted by the application. Protect your OS account,
backups, and device storage. Notification content may be visible through the OS.

For a suspected vulnerability, use GitHub's private vulnerability reporting if
enabled, or contact the repository owner privately through GitHub. Do not publish
exploitable details or real task databases in public issues. Include the affected
version, platform, reproduction steps, and a minimal example with synthetic data.

No response-time guarantee or supported-version policy has been established yet.
Keep dependencies and your platform toolchain current; run the full checks when
upgrading. Never include signing keys, credentials, or personal databases in a PR.
